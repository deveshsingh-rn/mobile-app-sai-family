# App Store Screenshot Selection

These are unchanged copies of actual app screenshots, ordered for upload.
Original files remain untouched. No UI or sample content has been fabricated.

## Selected screenshots

1. `iphone-1179x2556/01-ask-sai.png` - IMG_4327.PNG
2. `iphone-1179x2556/02-naam-jap.png` - IMG_4324.PNG
3. `iphone-1179x2556/03-community-directory.png` - IMG_4323.PNG

All three are portrait PNGs at 1179 x 2556 pixels. Select the matching
device-size slot in App Store Connect's media manager. Do not upload these
as iPad screenshots or assume they satisfy a different mandatory size slot.

Apple specifications:
https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/

## Before public submission

- Confirm these screens match the submitted build. The home screenshot in
  the original set has top navigation, whereas other screenshots have bottom
  navigation; recapture from the final binary if the UI has changed.
- Confirm permission to publish the profile photo visible in the directory.
- The transparent bottom dock overlays text in the screenshots. Prefer a
  fresh capture with unobscured content before final marketing submission.
- Capture actual required larger iPhone and iPad screenshots if requested by
  App Store Connect. Do not stretch phone screenshots into tablet layouts.
- Add a clean feed screenshot with representative devotional content and an
  events screenshot with a real, authorized event banner and useful details.
